# Optimisation de portefeuille sur le CAC 40

Est-ce que les méthodes pour répartir son argent entre des actions font mieux que de tout mettre à parts égales ?

Je travaille sur 32 actions du CAC 40 entre 2015 et 2025, avec les cours de Yahoo Finance.

Je compare parts égales, risque minimal, Markowitz, deux méthodes par regroupement d'actions, et l'indice.

Chaque mois, le portefeuille est recalculé avec l'année passée, puis testé sur le mois suivant, frais compris.

Projet en cours, je n'ai pas encore lancé le test sur les vraies données.

Pour le lancer, `pip install -r requirements.txt` puis `python run_backtest.py`.
